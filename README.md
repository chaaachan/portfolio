# Portfolio

Next.jsで作成した3ページ構成のポートフォリオです。

## 起動方法

VS Codeでこのフォルダを開き、ターミナルで次を実行します。

```bash
npm install
npm run dev
```

表示された `http://localhost:3000` をブラウザで開いてください。

## ページ

- `/`：Top page
- `/profile`：Profile
- `/to-everyone`：To everyone

## フォントについて

トップページの見出しは `Vonk Pro Medium` を指定しています。端末にフォントがない場合は代替フォントになります。Webフォントとして確実に表示する場合は、利用許諾のあるフォントファイルを追加してください。
